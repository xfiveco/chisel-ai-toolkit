# Twig Component Template

File contents for a reusable Twig component. Paths and prefixes: [file-locations.md](.claude/chisel/reference/file-locations.md). Timber context and include syntax: [twig-templating.md](.claude/chisel/reference/twig-templating.md). Procedure: [create-component](.claude/skills/chisel-create-component/SKILL.md).

## Twig template

`views/components/{name}.twig`:

```twig
{# Component: {Component Name} #}
{# @param {type} {param_name} - {description} #}

<div class="c-{name}">
  {% if param_name is defined and param_name %}
    <div class="c-{name}__element">{{ param_name }}</div>
  {% endif %}
</div>
```

Usage:

```twig
{% include 'components/{name}.twig' with { param_name: value } %}
```

## SCSS

`src/styles/components/_{name}.scss`:

```scss
@use '~design' as *;

.c-{name} {
  // BEM
  &__element { /* ... */ }
  &--modifier { /* ... */ }
}
```

`_index.scss` is auto-generated by the build — never edit it by hand.

## JS module (optional)

`src/scripts/modules/{name}.js`:

```js
class ComponentName {
  constructor(element) {
    this.element = element;
    this.initSelectors();
    this.initElements();
  }
  initSelectors() {
    this.selectors = {
      /* js-* */
    };
  }
  initElements() {
    this.elements = {
      /* cached */
    };
  }
}

export default ComponentName;
```

Import in `src/scripts/app.js`:

```js
import ComponentName from './modules/{name}';
new ComponentName();
```

This layer is for global/site-wide behavior. A **block's** frontend JS never goes here — it lives in the block's own `view.js`: [blocks.md "Block JS/CSS keys"](.claude/chisel/reference/blocks.md#block-jscss-keys--what-each-file-is-for).

## Objects

Atomic/abstract primitives (icon wrapper, badge) use the same shapes with the `o-` prefix: `views/objects/{name}.twig`, `src/styles/objects/_{name}.scss`, class `.o-{name}`.
